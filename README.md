SkillForge is a compact Python toolkit for creating agent skills from a plain JSON specification. It takes a skill definition, emits a ready-to-use Python class, and gives agent tooling a predictable build path from design to code.

## Overview

The project is intentionally small and practical: a CLI plus a compiler. It keeps the workflow focused on the real value proposition of agent systems: define a skill once, compile it into executable Python, and integrate it with your tooling without hand-writing boilerplate.

### What it does

- Reads a skill definition from a JSON file.
- Extracts the skill title from the `info.title` field.
- Generates a Python class with a standard `execute(self, **kwargs)` method.
- Writes the compiled skill to a target file through the CLI.

### Who it is for

- Engineers building agent workflows and reusable skill modules.
- Tooling teams that want a consistent way to generate code from specs.
- Prototypes and internal systems that need a lightweight compiler pattern.

## Why it exists

In agent-driven systems, the challenge is not just describing a capability, but turning that description into something executable and traceable. SkillForge addresses that by providing a simple compiler boundary: a clear input contract, deterministic output, and a fast path from specification to code.

The current implementation is deliberately minimal and transparent, which makes it easy to extend for stronger validation, richer templates, or more advanced skill generation workflows.

## Architecture

```text
JSON skill spec
      ↓
SkillCompiler.compile_from_spec()
      ↓
Generated Python skill class
      ↓
execute(self, **kwargs)
```

The core implementation is intentionally narrow:

- `src/skillforge/compiler.py` contains the generation logic.
- `src/skillforge/cli.py` exposes command-line entry points.
- `pyproject.toml` registers the `skillforge` console script.

## Quick start

Create a JSON spec file like this:

```json
{
  "info": {
    "title": "Web Search Agent"
  }
}
```

Then compile it:

```bash
skillforge --spec skill.json --out generated_skill.py
```

This creates a Python file similar to:

```python
# Auto-generated by SkillForge v1.0.0
class WebSearchAgentSkill:
    name = "web search agent"
    def execute(self, **kwargs):
        print(f"Executing {self.name} with parameters: {kwargs}")
        return {"status": "success", "data": kwargs}
```

## Usage example

```bash
skillforge --spec examples/agent_skill.json --out build/agent_skill.py
python build/agent_skill.py
```

A generated skill is a Python class; the actual integration point depends on your agent framework or execution environment.

## Configuration and inputs

The current compiler reads only the `info.title` field from the input JSON and derives the class name from it. That is the primary contract today.

```json
{
  "info": {
    "title": "My Tool"
  }
}
```

The tool then normalizes the title into a Python class name and uses a simple default method implementation.
